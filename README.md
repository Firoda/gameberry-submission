# 1010! Block Battle: a PM case for Gameberry Labs

A 5-slide web deck (intro + 4) proposing **Block Battle**, a 3-minute head-to-head mode for 1010! Block Puzzle where your line clears send junk rows to your rival's board. The goal: +10% DAU.
